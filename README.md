# Max Payne Passthrough

Мод, который переносит анимации и Euphoria-рагдолл Max Payne 3 в Max Payne 1.
Обе игры запущены одновременно: MP3 работает «движком анимации» — его
марионетки (Макс и враги) проигрывают анимации и физические реакции, а позы
их костей в реальном времени передаются в MP1 и применяются к персонажам MP1.

```
 Max Payne 1 (mp1phys.asi)                    Max Payne 3 (mp3bridge.asi)
 ─────────────────────────                    ───────────────────────────
 события: попадания, смерти,  ── команды ──▶  марионетки: спавн, попадания,
 действия игрока, bullet time                 анимации, Euphoria, time scale
 скелет MP1 ◀─ ретаргетинг ◀── позы костей ── скелеты педов MP3
 Rapier: коллизии с уровнем MP1
```

## Состав

| Путь | Что это |
|---|---|
| `crates/bridge` | Протокол через общую память Windows: снимки поз (seqlock), очередь команд (SPSC), heartbeat. Раскладка одинакова для 32- и 64-битных сборок. |
| `crates/ragdoll` | Физика рагдолла на Rapier: тела на костях, суставы с лимитами, импульсы пуль, bullet time через фиксированный шаг, слежение тел за целевыми позами с силой 0–1 и ограниченными скоростью и ускорением. В MP1 тела будут следовать позам из MP3, сталкиваясь с геометрией уровней MP1. |
| `crates/winmod` | Общая обвязка внедряемых DLL: `DllMain`, лог, список модулей. |
| `crates/mp1` | `mp1phys.asi` для Max Payne 1. |
| `crates/mp3` | `mp3bridge.asi` для Max Payne 3. |
| `tools/recon.py` | Разведка установки игры: версии, хеши, экспорты/импорты, C++-классы, признаки DRM, варианты загрузчика ASI. |

## Этапы

1. **Связь.** Обе DLL загружаются, видят друг друга через общую память. ← сейчас
2. **Разведка.** Найти в MP1 скелет персонажа, кадр игры, попадания и смерти;
   в MP3 — скелеты педов и нативы Script Hook для марионеток.
3. **Зеркало Макса.** Поза Макса из MP3 применяется к Максу в MP1.
4. **Управление.** Ввод и состояние Макса в MP1 (бег, шутдодж, прицел)
   управляют марионеткой в MP3; синхронизация bullet time.
5. **Враги.** Попадание в MP1 → такое же попадание по марионетке в MP3 →
   Euphoria-реакция и смерть возвращаются в MP1; Rapier удерживает тела от
   прохода сквозь стены MP1.
6. **Механики MP3**, которых в MP1 нет: стрельба лёжа после шутдоджа,
   last stand, bullet cam.

## Разведка

```
python tools/recon.py "C:\Program Files (x86)\Max Payne" --out recon\mp1
python tools/recon.py "<папка Max Payne 3>" --out recon\mp3
```

Скрипт только читает файлы игры. В каждой папке получатся `recon.md` (сводка
для чата) и `recon.json` (полные данные).

## Сборка

Готовые `.asi` собирает CI: вкладка Actions → последний запуск `build` →
артефакт `maxpayne-passthrough`. Локально (Windows):

```
rustup target add i686-pc-windows-msvc x86_64-pc-windows-msvc
cargo test --workspace
cargo build --release -p mp1phys --target i686-pc-windows-msvc
```

## Установка (этап 1)

* **Max Payne 1:** Ultimate ASI Loader под именем библиотеки, которую игра
  действительно загружает (смотри раздел «Injection» в отчёте recon), и
  `mp1phys.asi` рядом с `MaxPayne.exe`. Папка в Program Files требует прав
  администратора.
* **Max Payne 3:** Script Hook (его `dinput8.dll` загружает `.asi`) и
  `mp3bridge.asi` нужной разрядности. Только одиночная игра, без сети.

Проверка: запустить обе игры. В `mp1phys.log` должно появиться
`Max Payne 3 connected`, в `mp3bridge.log` — `Max Payne 1 connected`.

## Правила

В репозитории только свой код. Файлы игр (ассеты, исполняемые файлы, дампы)
не коммитятся: мод работает с копиями игр пользователя.
